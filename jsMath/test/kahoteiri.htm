加法定理の証明

\sin(\alpha＋\beta)＝\sin\alpha\cos\beta＋\cos\alpha\sin\beta
\sin(\alpha－\beta)＝\sin\alpha\cos\beta－\cos\alpha\sin\beta
\cos(\alpha＋\beta)＝\cos\alpha\cos\beta－\sin\alpha\sin\beta
\cos(\alpha－\beta)＝\cos\alpha\cos\beta＋\sin\alpha\sin\beta
\tan(\alpha＋\beta)＝{\tan\alpha＋\tan\beta \over 1－ \tan\alpha\tan\beta}
\tan(\alpha－\beta)＝{\tan\alpha－\tan\beta \over 1＋ \tan\alpha\tan\beta}

＜証明の補足＞

\sin^2\theta＋\cos^2\theta＝1  である証明
余弦定理の証明
\cos(－\beta)＝\cos(\beta)
\sin(－\beta)＝－\sin(\beta)  である事の図説
\cos(90°－\theta)＝\sin\theta  である証明

\cos(\alpha－\beta)＝\cos\alpha\cos\beta＋\sin\alpha\sin\beta の導出

単位円上の任意の点 、

P(\cos\alpha,\sin\alpha)、Q(\cos\beta,\sin\beta)

について、三平方の定理から、

PQ^2＝(\cos\alpha－\cos\beta)^2＋(\sin\alpha－\sin\beta)^2
＝\cos^2\alpha－2\cos\alpha\cos\beta＋\cos^2\beta＋\sin^2\alpha－2\sin\alpha\sin\beta＋\sin^2\beta
\sin^2\theta＋\cos^2\theta＝1 なので、
＝2－2\cos\alpha\cos\beta－2\sin\alpha\sin\beta             …①

また、余弦定理から、

PQ^2＝1^2＋1^2－2\cos(\alpha－\beta)
＝2－2\cos(\alpha－\beta)                                  …②

① = ② なので、

2－2\cos\alpha\cos\beta－2\sin\alpha\sin\beta＝2－2\cos(\alpha－\beta)

式を整理して、

\cos(\alpha－\beta)＝\cos\alpha\cos\beta＋\sin\alpha\sin\beta

を導出できる。

\cos(\alpha＋\beta)＝\cos\alpha\cos\beta－\sin\alpha\sin\beta の導出

\cos(\alpha－\beta)＝\cos\alpha\cos\beta＋\sin\alpha\sin\beta
の、\beta を (－\beta)  に置き換える。
\cos(\alpha－(－\beta))＝\cos\alpha\cos(－\beta)＋\sin\alpha\sin(－\beta)
\cos(－\beta) ＝ \cos(\beta)、\sin(－\beta) ＝ －\sin(\beta)   なので、公式、
\cos(\alpha＋\beta)＝\cos\alpha\cos\beta－\sin\alpha\sin\beta

を導出できる。

\sin(\alpha＋\beta)＝\sin\alpha\cos\beta＋\cos\alpha\sin\beta の導出

\cos(\alpha－\beta)＝\cos\alpha\cos\beta＋\sin\alpha\sin\beta
の、\alpha を、 (90°－\alpha)  に置き換える。
\cos((90°－\alpha)－\beta)＝\cos(90°－\alpha)\cos\beta＋\sin(90°－\alpha)\sin\beta
\cos(90°－\theta)＝\sin\theta  なので、

左辺、

\cos((90°－\alpha)－\beta)＝\cos(90°－(\alpha＋\beta)
＝\sin(\alpha＋\beta)
　また、 \sin90°－\theta＝\cos\theta なので、

右辺、

\cos(90°－\alpha)\cos\beta＋\sin(90°－\alpha)\sin\beta＝\sin\alpha\cos\beta＋\cos\alpha\sin\beta

右辺 = 左辺で、

\sin(\alpha＋\beta)＝\sin\alpha\cos\beta＋\cos\alpha\sin\beta

を導出できる。

\sin(\alpha－\beta)＝\sin\alpha\cos\beta－\cos\alpha\sin\beta の導出

\sin(\alpha＋\beta)＝\sin\alpha\cos\beta＋\cos\alpha\sin\beta の、\beta　を　(－\beta)   に置き換える。
\sin(\alpha＋(－\beta))＝\sin\alpha\cos(－\beta)＋\cos\alpha\sin(－\beta)
\sin(－\beta)＝－\sin(\beta) 、 \cos(－\beta)＝\cos(\beta)  なので、公式、
\sin(\alpha－\beta)＝\sin\alpha\cos\beta－\cos\alpha\sin\beta

を導出できる。

\tan(\alpha＋\beta)＝\frac{\tan\alpha＋\tan\beta}{1－\tan\alpha\tan\beta} の導出

\tan(\alpha＋\beta)＝\frac{\sin(\alpha＋\beta)}{\cos(\alpha＋\beta)} より、
\tan(\alpha＋\beta)＝\frac{\sin\alpha\cos\beta＋\cos\alpha\sin\beta}{\cos\alpha\cos\beta－\sin\alpha\sin\beta}
分子・分母を　 \cos\alpha\cos\beta 　で割る。
\tan(\alpha+\beta)=\frac{\frac{\sin\alpha\cos\beta}{\cos\alpha\cos\beta}+\frac{\cos\alpha\sin\beta}{\cos\alpha\cos\beta}} {\frac{\cos\alpha\cos\beta}{\cos\alpha\cos\beta}-\frac{\sin\alpha\sin\beta}{\cos\alpha\cos\beta}}

式を整理して、公式、

\tan(\alpha＋\beta)＝{\tan\alpha＋\tan\beta \over 1－ \tan\alpha\tan\beta}

を導出できる。

\tan(\alpha－\beta)＝\frac{\tan\alpha－\tan\beta}{1＋\tan\alpha\tan\beta} の導出

\tan(\alpha－\beta)＝\frac{\sin(\alpha－\beta)}{\cos(\alpha－\beta)} より、
\tan(\alpha－\beta)＝\frac{\sin\alpha\cos\beta－\cos\alpha\sin\beta}{\cos\alpha\cos\beta＋\sin\alpha\sin\beta}
分子・分母を　 \cos\alpha\cos\beta 　で割る。
\tan(\alpha-\beta)=\frac{\frac{\sin\alpha\cos\beta}{\cos\alpha\cos\beta}-\frac{\cos\alpha\sin\beta}{\cos\alpha\cos\beta}} {\frac{\cos\alpha\cos\beta}{\cos\alpha\cos\beta}+\frac{\sin\alpha\sin\beta}{\cos\alpha\cos\beta}}

式を整理して、公式、

\tan(\alpha－\beta)＝{\tan\alpha＝\tan\beta \over 1＋\tan\alpha\tan\beta}

を導出できる。

＜証明の補足＞

\sin^2\theta＋\cos^2\theta＝1 の証明

直角三角形ABCにおいて、

\sin\theta=\frac{a}{b}
\cos\theta=\frac{c}{b}
∴
\sin^2\theta＋\cos^2\theta＝\frac{a^2}{b^2}＋\frac{c^2}{b^2}
＝\frac{a^2＋c^2}{b^2}

三平方の定理 より、

\sin^2\theta＋\cos^2\theta＝1 を導く事が出来る。（証明おわり）

余弦定理の証明

三平方の定理では直角三角形の三角比を求める事が出来るが、 余弦定理を使うと、三角形一般の２辺と、その２辺に挟まれる角度から残る一辺の長さが求まる。

△ABCにおいて以下の関係式が成り立つ。

a^2＝b^2＋c^2－2bc \cos A
b^2＝a^2＋c^2－2ac \cos B
c^2＝a^2＋b^2－2ab \cos C

∠Aの角度と∠Aを挟む辺 b、cの長さが判っている場合の証明

△ABCについて、

a^2＝b^2 \sin^2 A＋(c－b \cos A)^2
＝b^2   \sin^2 A＋c^2－2   c   b   \cos A＋b^2   \cos^2 A
＝b^2(\sin^2 A＋\cos^2 A)＋c^2－2cb \cos A
＝b^2＋c^2－2cb \cos A

∴ 以下の式は成り立つ。

a^2＝b^2＋c^2－2bc \cos A

∠b、∠cについても同じ事が言えるので、

b^2＝a^2＋c^2－2ac \cos B
c^2＝a^2＋b^2－2ab \cos C

上記２つの式も成り立つ。（証明おわり）

因みに、∠Aが90度の時 cosA = 0 になり、余弦定理の中に三平方の定理が現れる。

\cos(－\beta)＝\cos(\beta)、\sin(－\beta)＝－\sin(\beta) である事の図説

\cos(90°－\theta)＝\sin\theta の証明

図より、直角三角形ABCにおいて以下の関係式が成り立つ。

\sin A＝\frac{CB}{AC}＝\cos C＝\sin (90°－ C)
\cos A＝\frac{AB}{AC}＝\sin C＝\cos (90°－ C)
\tan A＝\frac{CB}{AB}＝\frac{1}{\tan C}
\tan C＝\frac{AB}{CB}＝\frac{1}{\tan A}

\cos A＝\frac{AB}{AC}＝\sin C＝\cos (90°－ C)  より、
式\cos(90°－\theta)＝\sin\theta  は成り立つ。

（証明おわり）
