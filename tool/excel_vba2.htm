>・・・・照合の型って0じゃなくて・・・？			
大量データの検索をやる場合は、特に検査範囲が広い			
場合、Matchの照合の型0を使うのは馬鹿げたことです。			
毎回最初から一つ一つなめて検索していきますから、			
時間がかかってしょうがないです。			

Matchを使う場合は、検査範囲をソートして照合の型を
1(あるいは省略)にしたほうが良いですよ。
照合の型が0は逐次探索(馬鹿サーチ)なのにたいして、
照合の型が1や-1は二分探索(バイナリサーチ)なので、
速度が全然違います。

注意点は検査範囲はきちんとデータ範囲にすることです。
見出しを含めるのはもちろんご法度ですが、余分に
後ろの空白を含めるのもご法度です。
あべこべに照合の型0より遅くなってしまいます。

On Error GoTo ERR_ブック名の上書き回避
Application.DisplayAlerts = False
intI = 0

strWBname = "sample"
intWBname = Len(strWBname)
myUndo:
If Dir(ThisWorkbook.Path & strWBname & ".xls") <> "" Then GoTo REname

ThisWorkbook.SaveAs Filename:=ThisWorkbook.Path & strWBname & ".xls"
Exit Sub
REname:
intI = intI + 1
strWBname = Left(strWBname, intWBname) & "(" & intI & ")"
GoTo myUndo
Exit Sub
ERR_ブック名の上書き回避:
MsgBox Err.Number & " : " & Err.Description

End Sub

Sub webのパスワードを突破パターン1()
    Dim ie    As Object
    Dim Obj1  As Object
    Set ie = CreateObject("internetexplorer.application")
    ie.Visible = True
    ie.navigate "http://www.google.co.jp/"
    While ie.busy
        DoEvents
    Wend
    Application.Wait Now + TimeValue("00:00:02")
    Set Obj1 = ie.document
    With Obj1.all
        .q.Value = "エクセル vba"
        .btnG.Click
    End With
End Sub
