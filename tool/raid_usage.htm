RAID構成設定手順の覚書


パソコンDELL Dimension 9150 での、RAID構成設定にあたり、何度か行き詰りながら
作業をしたので、今後の備忘録として以下に手順を記す。
OSはWIN_XP_Professinal

RAID構成を以下の手順で作成すると
データは全て失われる。この記事は、HDD障害のため
２台の新品のHDDを取り付けた際の手順である。

RAIDの管理ツール：Intel Matrix Strage Consoleを使用すれば
データを失うことなくRAID構成を構築できる（と思われる）。

１．同じ容量のHDDを２台（Ａ、Ｂ）を用意する。
　　（容量が同じである必要はないが、違う容量のHDDの
　　組み合わせだと、未使用の領域が出来てしまうので
　　より大容量のHDDの方が勿体無い事になる）

２．PC本体にHDDを２台とりつける。

３．PCの電源をいれ、F2キーを使ってセットアップユーティリティを表示させ、
　　以下の設定をする。
　　・Boot Sequence にて、起動用ドライブの優先順位を
　　　1.CD-ROM、2.SATA HDDドライブ

４．リカバリーCDをセットし電源を切り、再び電源を入れる。

５．HDD（Ａ）にＯＳがインストールされる。

６．リカバリーディスクとは別にRESORECE CDが付属しているので
　　こちらも忘れずにインストールする。このディスクには、

　　・ネットワークドライバ
　　・画面表示を滑らかにする何か
　　・サウンドドライバ

　　とPC利用には必須の機能が含まれているほか、

　　・RAIDの管理ツール：Intel Matrix Strage Console

　　が含まれている。この管理ツールはRAID構成のタメに
　　必須ではないのかもしれないが、RAID構成後に
　　RAIDが正常に機能しているかどうか確認できるので
　　あるに越したことはない。　

７．WINDOWSが起動したら、
　　コントロールパネル⇒管理ツール⇒コンピュータの管理を起動し、
　　ディスクの管理からHDD（B）をフォーマットする。
　　フォーマットすることによりOSからHDD（Ｂ）が見えるようになる。

８．３の手順より、SATA HDDの優先順位を１位に上げ、
　　Drivers ⇒SATA Operationに進み、RAID ON を選択する。

９．この状態で起動すると、起動時にRAID構成のタメに
　　Ctrl + i を押せというプロンプトが表示される。
　　Ctrl + i で画面を進み、RAID０（ストライプ）かRAID１（ミラーリング）を
　　選択する。英語のみの画面だが、難しい事はない。

　　尚、RAID０はパフォーマンスは向上が期待でき、
　　ディスク領域をフルで使用できるが
　　HDD障害がおきるとデータの救済ができない。

　　RAID１はHDD容量の半分は無駄になりアクセス速度も
　　犠牲になるが、片方のHDDが障害を起こしても、HDD
　　交換の際もPCを止めることなく、シームレスに作業を
　　続けることができるとされている。

　　現実には、多分どっちのディスクが障害起こしているのか、
　　判断できないと思う（全く同じ製品のHDDを２台使っているので）。

　　・HDDを外して起動するかどうか試す
　　
　　という手順を踏まないと判断できそうにないので、
　　シームレスというわけには行きそうにない。


１０．続けて起動すると、HDDが２台あるのに
　　　１台として表示されていることと、
　　　RAIDの管理ツール：Intel Matrix Strage Console
　　　から、RAIDが正常に機能している事を確認できる。
