イベントをキャンセルするには、イベントハンドラが戻り値として false を返す 必要があります。ただし、その際、イベントハンドラ呼びだし元のコードに、「return」を 付与するのを忘れないようにしてください。onsubmit="process()" では戻り値が イベントに返されませんので、イベントもキャンセルされません。

フォーム要素にアクセスするには、form と アクセスしたい要素に name属性を指定します。 


   document.フォーム名.要素名

他の方法として、forms／elements 配列を経由する方法もあります。 forms配列はページ内に含まれる全てのフォームを格納する配列、elements配列はフォーム内に 含まれる要素を格納する配列です。上の例での var name = document.fm.name.value; は、次のように書き換えられます。 


   var name = document.forms[0].elements[0].value;



   var name = document.forms['fm'].elements['name'].value;
var name = document.forms['fm']['name'].value; var name = document.forms[0]['name'].value;

フォーム要素共通プロパティ／メソッド

フォーム要素は、大きく以下のように分類できます。

分類 要素名 概要
テキスト Text(<input type="text">) テキストボックス
Password(<input type="password">) パスワード入力ボックス
Textarea(<input type="textarea">) 複数行テキスト入力ボックス
ラジオ／チェック Radio(<input type="radio">) ラジオボタン（単一選択）
Checkbox(<input type="checkbox">) チェックボックス（複数選択）
選択 Select(<select>) 選択ボックス（単一選択）
Select(<select multiple>) リストボックス（複数選択も可）
ボタン Submit(<input type="submit">) 確定（送信ボタン）
Reset(<input type="reset">) リセット（キャンセルボタン）
Button(<input type="button">) 一般的なボタン
その他 File(<input type="file">) ファイル選択ボックス
Hidden(<input type="hidden">) 隠しフィールド

それぞれの要素に用事て、りようできるプロパティやメソッドも異なりますが、 以下のプロパティ／メソッドは共通して利用できます。

メンバ概要
form要素が属するフォーム要素（Formオブジェクト）を取得
disabled要素の入力／選択を禁止するか
name要素名（読みとり専用）
type要素の種類（text, button, radioなど）（読みとり専用）
value要素の値（ただし、<タグでは利用不可>）
focus()要素にフォーカスをセットする
blur()要素からフォーカスを外す

このようなケースにおいて、「document.fm.food」は（Elementオブジェクト ではなく）Elementオブジェクトの配列となる点に要注意です。個々の要素にアクセスするには 以下のように記述する必要があります。 


   document.フォーム名.要素名[インデックス番号]

   document.フォーム名.要素名.length

チェックボックスが一つしかない場合は、配列ではない形式で記述します。 


   document.フォーム.要素名

6-5 表示ページのアドレス情報を取得／操作する - Location オブジェクト -

クエリ情報を取得する

form method="POST" で送信するポストデータが、まとまった情報を送信するのに適しているのに 対して、ちょっとしたキー情報を受け渡しするのに向いているのがクエリ情報です。 URL の末尾「?～」以降に付加された簡易なデータのことです。「キー名=値」で記述します。

JavaScript では Search プロパティを利用することで、クエリ情報を取得することができます。 ただし、search プロパティの戻り値は以下のような単なる文字列です。 


   ?id=12345&category=script…

キー／値の形式に分解するには、自分でちょっとしたコードを書き加える必要があります。 


    <!DOCTYPE html>

    <html lang="en" xmlns="http://www.w3.org/1999/xhtml">
    <head>
        <meta charset="utf-8" />
        <title>p238</title>
        <script type="text/javascript">
            <!--
            //選択ボックスが変更されたタイミングで実行
	    /*
	    '$'で始まるこの妙な関数名はたぶん実際のライブラリの関数名なの
            だと思われる。 function qqq() であっても動作する
            */
            function $q() {
                // 解決済みのクエリ情報を格納するための連想配列を用意
                var result = {};

                // クエリ情報の２文字目以降（つまり、「?」を除く部分）を抽出
                var str = location.search.substring(1);

                // 「&」で分割し、「キー名=値」という文字列を順に取得
                var params = str.split('&');

                for (var i = 0; i < params.length; i++) {
                    // 「キー名=値」を「=」で分割し、キーと値を取得
                    var kv = params[i].split('=');

                    // 値はエンコードされている可能性があるので、あらかじめデコード
                    result[kv[0]] = decodeURIComponent(kv[1]);// ビルトイン関数
                }
                // できあがった連想配列を戻り値として返す
                return result;
            }
            var q = $q();
            for (var el in q) {
                document.write(el + ':' + q[el] + '<br />');
            }

            // p238.html 先ずページにアクセスしてから
            // p238.html?id=12345&hoge=pugya にアクセスすると⇒
            /*
            id:12345
            hoge:pugya
            */
        
            //-->
        </script>
    </head>
    </html>
