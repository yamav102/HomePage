例外処理

try　…　catch　…　finally構文


   //構文
   try{
       例外が発生するかもしれない命令
   } catch (例外情報を受け取る変数) {
       例外が発生した時の命令
   }[finally {
       例外の有無に関わらず、最終的に実行される命令
   }]

例外情報を受け取る変数はなんでも良いわけではなく、 e を使う。 Errorオブジェクトを暗黙に参照している（？）。宣言しないでも使う事ができるし、 var e; としてもエラーにはならない。

try　…　catch　…　finally構文を使わない場合、エラーが発生した時点で スクリプトはそこで停止してしまうが、構文を使う事で処理を完了させる事が出来る。

try　…　catch　…　finally構文はオーバーヘッドの高い処理であるらしい。 よって、ループの中で使う事は、出来れば、避ける事が望ましい。 


   var i = 1;
   try{
       i = i * j; // 例外発生
   } catch (e) {
       document.writeln(e.message);
   } finally {
       document.writeln('<br />処理は完了しました。');
   }
   /*
   j is not defined　FireFox での表示
   処理は完了しました。 
   */

throw 命令

予測できるエラーはこれで対処する。 


   var x = 'a';   
   try {       
       // NaN. 読み：エンエイエン読み：ナン外語：NaN: Not a Number
       if (isNaN(x)) {
         throw new Error('数字ではない値を計算しようとしていますお');
       } 
       var y = 1 / x;
   } catch (e) {
       document.writeln(e.message);
   }
   // 数字ではない値を計算しようとしていますお

throw させるのは Error であって、error ではない。 error と書いてしまうと、書いてしまった事自体がエラーになるので、 error とerror is not defined（FireFox)と表示される。 しばらく何が起きているのかワケが判らなくなった。

javascript では０で除算してもエラーにならない。 ０除算がエラーにならない言語もあるのだそうで、次のコードは全くエラーにならない。 


   var x = 0;
   try {
       var y = 1 / x;
   } catch (e) {
       document.writeln(e.message);
   } finally {
       document.writeln('y は、' + y);
   }
   // y は、Infinity (∞無限）

０除算でエラーを発生させる為には、以下のように自ら Error を throw しておく必要がある。 


   var x = 0;
   try {
       var y = 1 / x;
       throw new Error('0で除算しようとしました。<br />');
   } catch (e) {
       document.writeln(e.message);
   } finally {
       document.writeln('y は、' + y);
   }
   /*
   0で除算しようとしました。
   y は、Infinity 
   */

Chapter3　基本データを操作する～組み込みオブジェクト

Chapter3-1 オブジェクトとは

静的プロパティ／静的メソッド

オリジナルには手を加えずに、コピー（インスタンス）をとって使い回すのが オブジェクト指向 と呼ぶと、その定義からはみ出すのが、例外的にインスタンスを生成せずに使うのが、 静的プロパティ／静的メソッド（クラスプロパティ／メソッドとも）。 インスタンスから呼び出す事は出来ない。

JavaScriptで扱うオブジェクトで、Array, Date, String, RegExp, Number, Error 等が、コアな 組み込みオブジェクト（Built-in Object）である。特別な宣言や定義をしなくても、利用できる。

オブジェクトとはすなわちデータ型だが、基本型では原則 new しないで 静的プロパティや静的メソッドを利用する。new しても使えるが（有害になる事が多いらしい）原則避ける。

組み込みオブジェクト
オブジェクト 概要
(Global) JavaScript の基本機能にアクセスするための手段を提供
Object すべてのオブジェクトのひな形となる機能を提供
Array 配列を操作する為の機能を提供
String 文字列を操作する為の手段を提供
Boolean 真偽値を操作する為の手段を提供
Number(object) 数値を操作する為の手段を提供
Math 数値演算を実行するための手段を提供
Date 日付けを操作する為の手段を提供
RegExp 正規表現に関わる機能を提供
Error エラー情報を管理

組み込みオブジェクトの中でも特に基本型である String, Number, Boolean を ラッパーオブジェクト と呼ぶ。単なる値にすぎない基本型の データを包んで（ラップして）、オブジェクトとしての 機能を機能を追加するためのオブジェクト。 


   var str = 'こんにちは！';     
   /*
   ラッパーオブジェクトは
   メソッドを持った型
   */
   document.writeln(str.length); // 6

var str = new String('こんにちは!'); とも書いても動作はするが、 組み込みオブジェクトに対しては、原則として避けるべきとされる。

Arrayオブジェクトのメソッドを扱う際の留意点

  • concat 、join、toString以外はオリジナルを直接変更する。
  • 配列の中身は toStringメソッドが便利。document.writelnメソッドなど 表示系のメソッドでは、配列オブジェクトを直接に渡す事で、内部的に toStringメソッドが 呼び出されるので、toStringメソッドで明示的に呼び出す必要が無い。
  • sortメソッドでは、引数としてユーザー定義関数を指定できる。（・引数は２つ： 比較する配列要素、・第一引数が第二引数より小さい場合は負数、大きい場合は整数を返す） 条件を満たす必要がある。） 

   var ary = [5, 25, 10];
   document.writeln(ary.sort()+'<br />');
   // 10, 25, 5 文字列としてソート

   document.writeln(ary.sort(
       function (x, y) { return x - y; }));

JavaScriptの配列はハッシュテーブルである。 コンストラクタで生成した場合の添え字としての引数は要素数。 だが、宣言した要素数を越えてもエラーも出さずに設定できるし、 値の無い要素は for in で廻した際に無視され undefined（未定義）を alert するか、 document.writelin なら null すら返さない。 また、配列のキーは数字である必要もなく、数字と解釈できる文字列は 数字として解釈され、文字列としてのキーは、lengthプロパティ が返す 数値にはカウントされない。lengthプロパティは、数値で指定されている 添え字の最大数に１を足した数を返すだけであって、要素数を返しているワケではない。

Arrayオブジェクトは、コストラクタで要素数を指定して 作成する意義を見出す事は難しい。反対に、Arrayオブジェクトの length プロパティは値の設定が可能であり、読みとり専用のプロパティではない。 要素数３の Arrayオブジェクトで ary.length = 1; を設定すれば、 キーが全て数字だった場合は、配列の要素数が 1 に切り詰められる。 この場合、キーに文字列が含まれた場合の配列要素は無視される。 


   var a=new Array();

   A

   a.length=1;

Chapter3-3日付／時刻データを操作する -Dateオブジェクト-

Dateオブジェクトを生成する

標準のデータ型としてdate型は存在しない。date型は組み込みオブジェクトである。 文字列は配列のようなリテラル表現は無い。ので、必ずコンストラクタ経由で生成する。 


   // デフォルトのDateオブジェクトを生成。
   // システムの日付けがセットされています。
   var d = new Date();
   document.writeln(d + '<br />');
   // Sun Jul 07 2013 12:01:55 GMT+0900
   
   // 日付け文字列をもとにDateオブジェクトを生成。
   var d = new Date('2013/7/7');

   // 年月日／時分秒／ミリ秒形式で生成
   var d = new Date(2013, 6, 7, 12, 5, 30, 999);

   // 月の指定は、1～12ではなく0～11である事に注意。
   document.writeln(d + '<br />');
   // Sun Jul 07 2013 12:05:30 GMT+0900

   // 1970/01/01 00:00:00からの経過ミリ秒（タイムスタンプ値）で指定する方法
   var d = new Date(1217862000000);
