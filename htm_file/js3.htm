matchメソッドと exec メソッドの挙動の違い

正規表現の検索には、String.matchメソッドのほかに、RegExp.execメソッドがある。 条件によって検索結果が両者で異なる場合がある。 


   /* 
   exec メソッドは g オプションを指定しても、
   １度の実行でひとつの実行しか返せない。
   */
   var p = /http(s)?:\/\/([\w-]+\.)+[\w-]+(\/[\w- .\/?%&=]*)?/gi;
   var str = '　サポートサイトはhttp://www.wings.msn.to/です。';
   str += 
     " サンプル紹介サイトHTTP://www.web-deli.com/も('-'*)ヨロシク♪";
   var result = p.exec(str);
   for(i = 0; i < result.length; i++){
       document.writeln(result[i]+'<br />');
   }
   /*
   http://www.wings.msn.to/
   undefined
   msn.
   /
   */

execメソッドでマッチした文字を全て返すには、execした結果が nullになるまで、何度も実行する。 最後にマッチした場所をRegExpオブジェクトは記憶しているので、以下のような書き方が出来る。 


   var p = /http(s)?:\/\/([\w-]+\.)+[\w-]+(\/[\w- .\/?%&=]*)?/gi;
   var str = '　サポートサイトはhttp://www.wings.msn.to/です。';
   str += " サンプル紹介サイトHTTP://www.web-deli.com/も('-'*)ヨロシク♪";
   
   while((result=p.exec(str)) != null){
       document.writeln(result[0]+'<br />');
   }
   /*
   http://www.wings.msn.to/
   HTTP://www.web-deli.com/
   */

インスタンスのオブジェクト型を判定する　- constructor プロパティ-

typeof 演算子は基本型を識別する事しか出来ません。参照型は object型としか返さない。 参照型（オブジェクト型）の変数を識別するには、constructorプロパティを使用する。 


   var data = [];
   if (typeof data == 'object' && data.constructor == Array) {
       document.writeln(
           '変数dataはArrayオブジェクトのインスタンスです。');
   }
   //変数dataはArrayオブジェクトのインスタンスです。

Objectオブジェクトの constructor プロパティが返すのはオブジェクトのコンストラクタである Functionオブジェクト。なので、data.constructor == 'Array' などと文字列と して比較してはいけない。

instanceof 演算子を使ってオブジェクトの型を判定する


   var data = [];
   if (typeof data == 'object' && data instanceof Array) {

	   '変数dataはArrayオブジェクトのインスタンスです。');

匿名オブジェクトを作成する

Objectオブジェクトの役割は、その他のオブジェクトに対して共通の機能を提供する 事ではなく、Objectオブジェクトを直接インスタンス化する事で、ユーザーが自前の オブジェクトを定義するのに利用できる。

このようなオブジェクトの事を「独自のオブジェクト名を持たない」という意味で、 匿名オブジェクト もしくは 無名オブジェクト と呼びます。 作成した直後は、オブジェクト共通のプロパティ／メソッドの他はなんらデータを持たない。 以下のように、プロパティを追加していく。 


   // 匿名オブジェクトを生成
   var obj = new Object();

   // プロパティの追加
   obj.name = 'トクジロウ';
   obj.birth = new Date(2013, 7, 17);
   obj.old = 5

   // プロパティにはドット演算子でアクセスできる
   document.writeln(obj.name);
   // トクジロウ

匿名オブジェクトとは言うけれど、obj という名前はつけているじゃん、 という話ではなくて、名前の付けようの無い Object オブジェクトを インスタンス化させたオブジェクトだから「匿名オブジェクト」と呼ぶのだと思う（多分）。 構造体のように使う。いちいちクラスを定義する必要がない分コードがシンプルになる。

匿名オブジェクトを生成するために、Objectオブジェクトではなく、 Array や Date のような既存の組み込みオブジェクトを利用する事も出来てしまう。 


   var obj = new Array();
   obj.name = "とくじろう";
   document.writeln(obj.name);
   // とくじろう

しかし、匿名オブジェクトを生成するために、これら特定の目的をもった オブジェクトをベースにする理由はなく、かえって間違いやバグの元となる 可能性がある。通常はオブジェクトとして中性的な機能のみを持つ Object オブジェクトを 使うべきです。

   };
   document.writeln(hoge.name);
   // ほげジロウ

「オブジェクトリテラルでオブジェクトを生成する」とは 「匿名オブジェクトを定義する」ことと同じ意味。

3-6 基本機能を提供する　- Globalオブジェクト -

Global オブジェクトとは、（言うなれば）グローバル変数やグローバル関数を 管理する為に JavaScript が自動的に生成する「便宜的な」オブジェクト。

var g = new Global(); とインスタンス化することは出来ない。また、 Global.メソッド名 のように配下のメソッドを呼び出せるわけでもない。 ただ単に、 


   変数名
   関数名(引数,…)

のように参照する。

データ型を明示的に変換する - parseFloat／parseInt／Number 関数 - 


   /*
   「123xxx」のような文字列混在の数値は
   parseXxxxx関数は 123 と解析できる部分を数値と
   して返す。
   Number関数は文字列混在の数値を数値と看做さない
   */
   var n = '123xxx';
   document.writeln(Number(n) + '<br />'); 
   // NaN

   document.writeln(parseFloat(n) + '<br />'); 
   // 123

   document.writeln(parseInt(n) + '<br />'); 
   // 123
   /*
   Dateオブジェクトが渡された場合、parseXxxxx関数は解析出来ず
   に NaN を返す。Number関数は「経過したミリ秒」に換算した値を
   返す。
   */
   var d = new Date();
   document.writeln(Number(d) + '<br />'); 
   // 1374326910891

   document.writeln(parseFloat(d) + '<br />'); 
   // NaN

   document.writeln(parseInt(d) + '<br />'); 
   // NaN

   /*
   8進数の整数リテラルの場合、parseInt だけが８進数を返し(?)、
   他の関数は 777 を返します…と説明されているが
   実際にはどれも 777 を返す。2012.8 に仕様が変更された
   */
   var h = '0777';
   document.writeln(Number(h) + '<br />');
   // 777

   document.writeln(parseFloat(h) + '<br />'); 
   // 777

   document.writeln(parseInt(h) + '<br />'); 
   // 777

   alert(parseInt(h,8));
   // 511

   alert(parseInt(h, 16)); 
   // 1911

   /*
   浮動小数点を渡すと、parseIntはe+2を無視して
   整数部分のみを切り捨てて返す
   */
   var e = '1.01e+2';
   document.writeln(Number(e) + '<br />'); 
   // 101

   document.writeln(parseFloat(e) + '<br />'); 
   // 101

   document.writeln(parseInt(e) + '<br />'); 
   // 1

   document.writeln(parseInt('1.9') + '<br />'); 
   // 1

   /*
   グローバルオブジェクトが提供するグローバル関数 Number は
   実は組み込みオブジェクトのNumberでもあるので、   
   */
   document.writeln(new Number(e)); 
   // 101
   /*
   とも書ける。
   */

データ型を明示的に文字列型、論理型に変換したい場合も同様で、 それぞれ String/Boolean関数を仕様します。Number関数と同様、 String/Boolean関数の実体はString/Booleanオブジェクトであり、 以下いずれの書き方をしても意味は同じになる。 


   var str = new String('123');
   var str = String('123');

   /*
      文字列⇔数値の変換では
      算術演算子「+」「-」を利用する事もできます
   */
   document.writeln(typeof (123 + '' + '<br />')); 
   // string

   document.writeln(typeof ('123' - 0 + '<br />')); 
   // string

+演算子は加算と文字列連結の２つの機能を持っているが、オペランドの 片方が文字列だった場合、文字列連結演算子として解釈される。

クエリ情報をエスケープ処理する - encodeURI／encodeURIComponent関数 -

URLの末尾～? 以降に「キー名=値＆…」の形式で記述されているのが、 サーバ乗で動くアプリケーションへの問い合わせに使われる「クエリ情報」。 クエリ情報には区切り文字である ? = % 空白 マルチバイト文字は 使用できない。ので、これらの文字は %xx の形式に変換しておく必要がある。 このような変換処理の事を URIエンコード と言う。 そして、そのような エスケープ処理 を行うのが encodeURI／encodeURIComponent 関数。両者は殆ど同じ機能を提供するが エンコード対象となる文字に若干の違いがある。 


   // encodeURI
   var str = '!"#$%&()+-/@_|;:,.';
   document.writeln(encodeURI(str) + '<br />'); 
   // !%22#$%25&()+-/@_%7C;:,.

   // decodeURI
   var str2 = '!%22#$%25&()+-/@_%7C;:,.';
   document.writeln(decodeURI(str2) + '<br />'); 
   // !"#$%&()+-/@_|;:,.

   // encodeURIComponent
   document.writeln(encodeURIComponent(str) + '<br />'); 
   // !%22%23%24%25%26()%2B-%2F%40_%7C%3B%3A%2C. 

   // decodeURIComponent
   var str3='!%22%23%24%25%26()%2B-%2F%40_%7C%3B%3A%2C.';
   document.writeln(decodeURIComponent(str3) + '<br />');
   // !"#$%&()+-/@_|;:,.

   /* 
    escape 関数によるエスケープ処理
   プラットフォーム・ブラウザ（種類／バージョン）、
   文字コード等によって結果が異なる。
  「下位互換性を胃jいしたい」など特別な理由が無い限り
   使うべきではない。
   */
   document.writeln(escape(str) + '<br />');
   // %21%22%23%24%25%26%28%29+-/@_%7C%3B%3A%2C.

   var str4 = '%21%22%23%24%25%26%28%29+-/@_%7C%3B%3A%2C.';
   document.writeln(unescape(str4) + '<br />');
   // !"#$%&()+-/@_|;:,.

encodeURIComponent関数では # $ + / @ ; : , 等も変換されているのに、 encodeURI関数では変換されない。! ( ) - * ~ _ 等はどっちの関数でも 変換されない。（どうやって使い分けるのだろう(๑´ω`๑) ？）

動的に生成したスクリプトを実行する　- eval関数 -

eval関数は、文字列をJavaScriptのコードとして評価／実行します。 


   var str = 'window.alert("eval 関数")';
   eval(str);// [eval 関数] とアラートされる

eval関数を使う事で自在で柔軟なコーディングができるように見えるが、 以下の理由で濫用は避けるべきとされる。

  • 第三者による任意のスクリプトが自由に実行できてしまう可能性がある。セキュリティリスク。
  • 通常のコードを実行するよりも処理速度が遅い。パフォーマンスの劣化。

eval 関数の利用は JSON データの解析する場合に留めておくべき。 その他の状況でeval関数を利用しているとしたら、他の方法で記述できないかを 検討するべき。eval is evil（eval関数は邪悪）とまで言われる。
