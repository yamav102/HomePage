変数宣言　Decleration

javascriptでは変数を宣言するべきではあるが、 宣言ぜずに変数を使用できる。 変数の型はある。値型(number/string/boolean/null/undefined)・参照型(array/object/fuction) 型はあっても型を宣言する事はできない。

var(variableの事) 付けて変数宣言するわけだが、var 無しで使う変数は広域変数になってしまう。 広域変数の管理は厄介なので var で宣言するべきである。javascript のスコープは 広域変数と局所変数の二つしかない。ブロックレベルのスコープという概念はない。

広域変数名がバッティングした場合はより後から読みこまれた変数が有効になる。 そして、後から宣言した変数は先に読みこまれた変数を上書きしてしまう。 広域変数同士のバッティングは厄介。複数のjsファイルを読み込んだ場合、このトラブルの回避方法はあるのだろうか？

document.write + '<br />' と document.writeln の違い

じゃあ、ブラウザ上では document.writeln() は役立たずなのでは？

まあ、改行を反映させる pre 要素と併用すれば、 いちいち <br> を書かずに済む、というメリットはあります。 

   document.writeln('あい、');
   document.writeln('うえお。');
   /*
   あい、
   うえお。
   */

余談ですが、XHTML では document.write() が使えませんので、 <br /> のように書かないで下さい。<br /> と書いているのに document.write() が動いているのなら、 それは XHTML ではなく HTML5 です。

ファイルの拡張子を .xhtml にするか、MIME タイプを application/xhtml+xml にして（IE 以外で）読み込んでみて下さい。 すでにモダンブラウザでは、XHTML モードで document.write() が動作しないようになっているはずです。

オブジェクトリテラル

オブジェクトとは、名前をキーにアクセスできる配列です。 ハッシュ、連想配列等と呼ばれます。

通常の配列がインデックス番号しかキーに出来ないのに対し、 オブジェクトでは文字列をキーにアクセスできるため、データの視認性が 高くなります。

JavaScriptにおいては、連想配列とオブジェクトは同一のものです。 「連想配列」と「オブジェクト」という言葉は、単にその時々の使い方 や文脈によって使い分けられているに過ぎません。 


   var obj = { x: 1, y: 2, z: 3 };
   document.writeln(obj.x); //1
   document.writeln(obj['x']); //1

   /*

   ○   obj['123']
   */

delete演算子

delete演算子は、オペランドに指定した変数や配列要素、オブジェクトのプロパティを破棄します。 削除に成功すると true 、失敗すると false を返します。 


   var ary = ['JavaScript', 'Ajax', 'ASP.NET'];
   document.writeln(delete ary[0]); // true
   document.writeln(ary); // ,Ajax,ASP.NET   ----------- ①
   var obj = { x: 1, y: 2 };
   document.writeln(delete obj.x); // true
   document.writeln(obj.x); // undefined
   var obj2 = { x: obj, y: 2 };
   document.writeln(delete obj2.x); // true
   document.writeln(obj); // [Object Object] ----------- ②
   var data1 = 1;
   document.writeln(delete data1); // false
   document.writeln(data1); // 1 ----------------------- ③
   data2 = 10;
   document.writeln(delete data2); // true
   document.writeln(data2); // エラー　（data2 は存在しない）
  • ①　配列要素の削除では、該当する要素が削除されるだけで、後ろの要素が繰り上がる訳ではない。 （インデックス番号は変わらない）
  • ②　プロパティを削除した場合、プロパティそのものが削除されるだけで、プロパティが参照するオブジェクトが削除されるわけではない。
  • ③　明示的に宣言された変数を削除することは出来ない

typeof演算子

typeof演算子は、オペランドに指定した変数／リテラルのデータ型を表す文字列を返します。 


   var num = 1;
   document.writeln(typeof num + '<br />'); // number
   var str = 'こんにちは';
   document.writeln(typeof str + '<br />'); // string
   var flag = true;
   document.writeln(typeof flag + '<br />'); //boolean
   var ary = ['JavaScript', 'Ajax', 'ASP.NET'];
   document.writeln(typeof ary + '<br />') //object
   var obj = { x: 1, y: 2 };
   document.writeln(typeof obj + '<br />'); //object

基本データ型の識別はできるが、配列、オブジェクト、ラッパーオブジェクトは object と看做される。どのような種類のオブジェクトなのか知りたい場合には instanceof 演算子 や constructorプロパティを使用する。
