         <!--

要素直下の子ノード群を取得するのは、childNodes プロパティの役割です。 childNodes プロパティは、getElementsByTagName メソッド同様、 取得したノード群を NodeList オブジェクトとして返しますが、 リストに含まれるノードは「要素だけではない」という点に要注意です。

タグの間にある改行や空白はテキストノードと看做されます。 そのため、childNodes プロパティもまた、要素ノードとテキストノードを取得する 可能性があるわけです。

今回のように <option> タグだけを取り出したい場合には、 取り出したノードが要素ノードであるかどうかを確認する必要があります。 ノードの種類を判定するのは、nodeType プロパティの役割です。

5ENTITY_REFERENCE_NODE：実体参照ノード
6ENTITY_NODE：実体宣言ノード

7-3 属性値を取得/設定する

多くの属性は「要素ノードの同名のプロパティ」としてアクセスできる

要素ノードにさえアクセスできてしまえば、属性値にアクセスするのは簡単です。 多くの属性は「要素ノードの同名のプロパティ」としてアクセスできるからです。 

<!DOCTYPE html>

<html lang="en" xmlns="http://www.w3.org/1999/xhtml">
<head>
    <meta charset="utf-8" />
    <title>p264</title>
    <script type="text/javascript">
        window.onload = function () {
            var result = [];
            var s = document.getElementsByTagName("a");
            for (var i = 0; i < s.length; i++) {
		//target属性の取得
                result.push(s.item(i).target);
		//href属性の設定
                s.item(i).href = "https://www.google.co.jp/search?q=yamav102&ie=utf-8&oe=utf-8&hl=ja"
            }
            window.alert(result.join(','));
        }
    </script>
    
</head>

<body>
    <p><a href="http://hogehoge.url/" target="_blank">hogehoge</a></p>
    
    <p><a href="http://fugafuga.url/" target="_parent">fugafuga</a></p>
    <p></p><a href="http://fushufushu.url/" target="_self">fushufushu</a></p>
</body>
</html>

attributesプロパティは、要素ノードに含まれる全属性のリストを NamedNodeMap オブジェクトと して返します。NamedNodeMap オブジェクトは、先述した NodeListオブジェクトにも似ていますが、 「個別のノードに名前、インデックス番号のいずれを使ってもアクセスできる」という特徴があります。

NamedNodeMapオブジェクトに含まれるノード（属性）を順に取得する流れは、NodeListオブジェクト の場合と同様です。インデックス数を 0 ～Length-1 まで変化させる事で、リストから属性ノードを ひとつずつ取り出しています。

取り出した属性ノードの名前／値にアクセスするには、nodeName／nodeValueプロパティを使用します。 両プロパティの戻り値は、使用するノードの種類によって異なりますが、属性ノードの場合は属性名／値を返します。

nodeName／nodeValueプロパティの戻り値（主要なもの）

要素 タグ名 null
属性 属性名 属性値
テキスト #text テキスト
コメント #comment テキスト
CDATAセクション #cdata-section テキスト
処理命令 ターゲット名 データ部
実体参照 実体参照名 null
文書 #document null
文書型宣言 文書型宣言名 null

ただし、Internet Explorer の attributes プロパティでは、タグに実際に指定していない属性も含めて （タグで利用可能なすべての属性が）出力されてしまいます。ここでは最低限 nodeValue プロパティが空 でない属性についてのみ出力するようにフィルタしています。

7-4 ノードを追加／置換／削除する

innerHTMLプロパティとどのように使い分けるか

ドキュメントの編集には、先述したinnerHTMLプロパティを利用する事も出来ます。 しかし、innterHTML プロパティがコンテンツを文字列として操作する必要があるのに対して、本節で紹介する方法ならば オブジェクト吊り―として操作できるため、「対象となるコンテンツが複雑になった場合にも、 コードの可読性が劣化しにくい」というメリットがあります。基本的には、以下のように使い分けて いくといいでしょう。

  • シンプルなコンテンツの編集　⇒　innnterHTMLプロパティ
  • 複雑なコンテンツの編集　⇒　本節のアプローチ

要素／テキストノードを作成する

コンテンツを追加するにはまず、createElement／createTextNode メソッドを利用して、新たに挿入する要素 ／テキストノードを生成します。 

<!-- 構文：createElement／createTextNodeメソッド -->
document.createElement(要素名)
document.createTextNode(テキスト)
⇒新たに要素／テキストノードを生成します。

createXxxxメソッドには、その他にも、生成するノードに応じて次ページの表のような メソッドがあります。

主なcreateXxxxxxメソッド
メソッド 生成するノード
createElement(要素名) 要素ノード
createAttribute(属性名) 属性ノード
createTextNode(テキスト) テキストノード
createCDATASection(テキスト) CDATAセクション
createComment(テキスト) コメントノード
createEntityReference(実体名) 実態参照ノード
createProcessingInstruction(ターゲット名,データ) 処理命令ノード
createDocumentFragment() ドキュメントの断片

createXxxxxメソッドで喉を生成する時点では、まだお互いの階層関係を意識する必要はありません。 生成された個々のノードは、パズルのピースのように、どこにも関連付けられず、バラバラに散らばっている状態です。

ノード同士を組み立てる

次に、このバラバラに散らばっているだけのノード群を組み立て、ドキュメントに追加する作業が必要になります。 この作業を行うのがappendChildメソッドの役割です。appnedChildメソッドは、追加された順番に 「一番最後の子要素として」指定された要素を追加します。 

<構文：appendChildメソッド>
要素ノード.appendChild(追加するノード)
⇒要素ノード直下の最後の子ノードとしてノードを追加します。

ここでは、まずテキストノードnameを要素ノードanchorに追加した上で、この要素ノードanchorとbrとを、 文書ツリー内の要素ノードlist配下に追加しています。

ちなみに、appendChildメソッドはinsertBeforeメソッドで置き換える事も出来ます。たとえば、 以下の２文は同意です。 

list.appendChild(anchor);
list.insertBefore(anchor, null);

insertBeforeメソッドでは、第１引数で指定したノードを第２引数で指定した子ノードの 直前に挿入します。appendChildメソッドと同様、最後尾にノードを追加したい場合には、第２引数に null を指定します。

逆に、先頭の子ノードとして追加したいと言う場合にには、以下のように書き換える事もできます。 

list.appencChild(anchor);
list.appendChild(br);
↓ 
list.insertBefore(br,list.firstChild);
list.insertBefore(anchor, br);
属性ノードを追加する

P.264でも述べたように、属性ノードを設定するには属性と同名のプロパティを設定するだけです。 ここでもその方法を用いていますが、createAttributeメソッドで属性ノードを生成することもできます。 プロパティを経由する場合に比べるとコードは冗長にないｒますが、属性名を文字列で指定できることから、 「スクリプトから動的に属性名を変更できる」というメリットがあります。より汎用的なコードを記述する 場合には利用する事もあるかと思いますので、リスト7-08の以下の部分をcreateAttributeメソッドで書き換えて見ましょう。 

anchor.href=f.url.value;

書き換えたコードは以下のとおりです。 

var href = document.createAttribute('href');
href.nodeValue = f.url.value;
anchor.setAttributeNode(href);

属性ノードの値を設定するには、nodeValueプロパティを使用します。

また、属性ノードを要素ノードに関連付けるには、appendChild／insertBeforeメソッドではなく、 setAttributeNodeメソッドを使用する点に注意して下さい。属性ノードは要素ノードの「子」ノードではなく、 属性という扱いだからです。

Note:setAttributeメソッドでも代用可能

ここではcreateAttributeメソッドを使った例を示したましたが、P264で紹介したsetAttributeメソッド を使用してもかまいません。
