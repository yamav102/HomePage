AppActivateステートメント メモ

AppActivate ステートメントは、アプリケーション ウィンドウをアクティブ化します。

「このアプリケーションのこのウィンドウをアクティブにしたい」のに前面に表示されず残念な思いをすることがあります。 この問題を解決してくれるかもしれないのが AppActivate です。 


～構文～
AppActivate title [, wait]

省略可能な第二引数は、この稿では考えません。 第一引数の title のヘルプの説明は次の通りです。

必須。アクティブ化するアプリケーション ウィンドウのタイトル バーに表示されるタイトルを指定する 文字列型 (String) の式です。Shell 関数から返されるタスク ID を title の代わりに使用してアプリケーションをアクティブ化することもできます。

title の値をどう取得するのかが考えどころです。一字一句間違えないように title を自分で記述できれば良いのですが、 文字列の半角・全角など間違えずに指定するのはとても難しく骨の折れる作業です。また、ファイル名がいつも同じともアレですので、 ハードコーディングは避けたいところです。

ヘルプの解説には次にようにあります。

アクティブ化するアプリケーションを判別する際、title が実行中の各アプリケーションのタイトル文字列と比較されます。完全に一致するものが見つからない場合は、タイトル文字列が title で始まるアプリケーションがすべてアクティブ化されます。title に一致するアプリケーションのインスタンスが複数ある場合は、1 つのインスタンスが任意にアクティブ化されます。

「完全一致でなくてもいいんだ゜+.(・∀・)゜+.゜」と「これならなんとかやりようがあるか」と希望をもって いくつかコードを試してみるのですが、私の試した範囲では、AppActivateステートメントが受け入れてくれる文字列は 例外もみつけましたが、完全一致した文字列でないと「プロシージャの呼び出し、または引数が不正です。」というエラーになりました。 また、ヘルプにある次のサンプルコードは動作しませんでした。 

AppActivate "Microsoft Word" ' Activate Microsoft 
 ' Word.

Shell関数から返されるタスクIDを指定する例は以下のようになります。 


Sub appactivateTest()
    
    Dim taskID As Integer
    taskID = Shell("C:\Program Files\Microsoft Office 15\root\office15\winword.exe", vbMaximizedFocus)
    VBA.AppActivate (taskID)
    
End Sub

アプリケーションのウィンドウだけを 指定したいのではなく、アプリケーションの更にその中のウィンドウを指定したい場合、このコードは 役に立ちません。また、Shell関数の第二引数で既にウィンドウにフォーカスを当てることが出来てしまうので、 AppActivateステートメントをここで使う意味があるとは思えません。

エクセル2013 で試した限りでは window の caption を title に指定したところアクティブウィンドウにする事が出来ました。 


Sub appactivateTest2()
    Dim wb As Workbook
    
    Set wb = Application.Workbooks.Open(ThisWorkbook.Path & "\sample.xlsx")
        
    Debug.Print wb.Windows(1).Caption
    VBA.AppActivate wb.Windows(1).Caption & " - Excel" '「& " - Excel"」部分は無くてもOK
    
End Sub

ワード2013 で試した限りでは window の caption に " - Word" を連結した文字列を title に指定したところ アクティブウィンドウにする事が出来ました。 


Sub appactivateTest3()
   
    Dim wdapp As Word.Application
    Set wdapp = New Word.Application
    
    With wdapp
        .Documents.Open ThisWorkbook.Path & "\文書2.docx"
        .Visible = True
        Debug.Print .Windows(1).Caption
        VBA.AppActivate .Windows(1).Caption & " - Word" '「& " - Word"」部分は必須
    End With
    
End Sub

ACCESSの場合ですが、Windows(1).Caption に当たるプロパティを見つけることが出来ませんでした。 あきらめて API関数を使うことにします。この関数はエクセルにでもワードにでも使えます。 


'modfunction
Option Explicit

'API関数の宣言
'ウィンドウのタイトルバーテキスト取得
Private Declare Function GetWindowText Lib "user32" _
    Alias "GetWindowTextA" _
    (ByVal hwnd As Long, ByVal lpString As String, _
    ByVal cch As Long) As Long
    
'ウインドウハンドルを渡してタイトルバーテキストを返します
Public Function GetWindowCaption(hwnd As Long) As String

    Dim str As String
    str = String(255, vbNullChar)
    
    'GetWindowText API関数
    GetWindowText hwnd, str, Len(str)
    str = Left$(str, InStr(str, vbNullChar) - 1)
    
    GetWindowCaption = str
    
End Function



Sub appactivateTest4()
    
    Dim tgtPath As String
    
    tgtPath = ThisWorkbook.Path & "\データベース1.accdb"
    
    Dim accApp As Access.Application 'Object
    
    Set accApp = VBA.GetObject(tgtPath)

    Dim winTitle As String
    winTitle = GetWindowCaption(accApp.hWndAccessApp)
    
    VBA.AppActivate winTitle
        
End Sub
