udlファイルの作り方


udlファイルはADOへの接続文字列の書き方が分からなくなった場合は
重宝かもしれない。
それ以外は、管理しなければならないファイルが一つ増えてしまうので
デメリットにしか感じられないが、作り方は以下の通り。

１．テキストファイルの拡張子を.udlにして開く

２．
こんな感じで開く↓





で、画面のように設定したudlファイルをテキストファイルで開くと、
'------------
[oledb]
; Everything after this line is an OLE DB initstring
Provider=Microsoft.Jet.OLEDB.4.0;Data Source=C:\Documents and Settings\やま\デスクトップ\test.mdb;Persist Security Info=False
'------------

↑となっていて、強調部分は ConnectionString そのもの。

64ビット環境ではudlが表示するドライバは64ビット用が表示される。
この中にJet は無い。

「Microsoft OLE DB プロバイダー Jet および Microsoft Access ODBC ドライバーは 32 ビット バージョンでのみ使用可能」
http://support.microsoft.com/kb/957570/ja

Office10以降（？）の64ビット版が
インストールされていれば 2007以降のDBエンジンであるACEが表示される（のだと思う）。
32ビット用のodbcad.exe(Open Data Base Connectivity Administrator)は
C:\Windows\SysWOW64 内にあるが、設定方法はよく判らない。

2007以降の接続文字列は、
string ConnectionString = "Provider=Microsoft.ACE.OLEDB.12.0;Data Source=sample.accdb";

コネクションを開く時 .Modeプロパティを指定することで排他制御が可能

 

 定数 値 説明 

 
 adModeRead 1 読み取り専用の権限を表します。 

 
 adModeReadWrite 3 読み取り/書き込み両方の権限を表します。
 
 
 adModeRecursive
 0x400000 カレント Record のすべてのサブレコードに共有制限を割り当てるために、
別の *ShareDeny* 値 (adModeShareDenyNone、
adModeShareDenyWrite、または adModeShareDenyRead) 
と組み合わせて使用します。Record に子がない場合は機能しません。
adModeShareDenyNone だけに使うと実行時エラーになります。
ただし、その他の値と結合すれば、adModeShareDenyNone 
に使うことができます。たとえば、"adModeRead
 Or adModeShareDenyNone Or adModeRecursive" は使用可能です。 

 
 adModeShareDenyNone 16 
権限の種類に関係なく、ほかのユーザーにも接続を許可します。
ほかのユーザーにも読み取り、書き込みの両方のアクセスを許可します。 

 
 adModeShareDenyRead 4 読み取り権限によるほかのユーザーからの接続を禁止します。 

 
 adModeShareDenyWrite 8 書き込み権限によるほかのユーザーからの接続を禁止します。 

 
 adModeShareExclusive 12 ほかのユーザーの接続を禁止します。 

 
 adModeUnknown 0 既定値です。権限が設定されていないか、設定が不明であることを表します。 

 
 adModeWrite 2 書き込み専用の権限を表します。 

 






    ■CursorTypeEnum値
    
        

            定数
            説明
        

        

            adOpenDynamic

            （動的カーソル）		
            ほかのユーザーによる追加、変更、削除を確認できます。Recordset 内でのすべての動作を許可します。プロバイダがブックマークをサポートしている場合は、ブックマークを利用できます。
        

        

            adOpenForwardOnly

            （前方専用カーソル）		
            ほかのユーザーによる追加、変更、削除は確認できません。レコードのスクロール方向が前方向に限定されていることを除き、静的カーソルと同じ働きをします。Recordset
            のスクロールが 1 回だけで十分な場合は、これでパフォーマンスを向上できます。（既定値）
        

        

            adOpenKeyset

            （キーセットカーソル）		
            動的カーソルと同様のはたらきをしますが、ほかのユーザーによるレコードの追加の確認、およびほかのユーザーが削除したレコードへのアクセスはできません。ほかのユーザーが変更したデータは表示できます。常にブックマークが使用できるため、Recordset
            内でのあらゆる種類の移動が可能です。
        

        

            adOpenStatic

            （静的カーソル）		
            データの検索またはレポートの作成に使用するための、レコード セットの静的コピーを提供します。常にブックマークが使用できるため、Recordset
            内でのあらゆる種類の移動が可能です。ほかのユーザーによる追加、変更、削除は表示されません。
        

    








    ■LockTypeEnum値
    
        

            定数
            説明
        

        

            adLockBatchOptimistic
            共有的バッチ更新を示します。
        

        

            adLockOptimistic
            レコードごとに共有的ロックをします。Update メソッドを呼び出した場合にのみ、共有的ロックを使ってそのレコードをロックします。
        

        

            adLockPessimistic
            レコードごとに排他ロックを行ないます。レコードの編集を開始するとロックが始まります。UpdateメソッドかCancelUpdateメソッドを実行するまで、他のユーザーはこのレコードの読み取り、編集を行なうことができません。
        

        

            adLockReadOnly
            読み取り専用のレコードを示します。データの変更はできません。
        

        

            adLockUnspecified
            ロックタイプを指定しません。
        

    








    Cursor Type・Lock Typeの値の組合せによるレコードセットのタイプ
    
        

            レコードセットのタイプ
            CursorType
            LockType
            options
            備考
        

        

            ダイナセット
            
            adLockOptimistic
            
            レコードの更新・追加・削除が可能で，編集結果は，レコードセットのもとになったテーブルに反映されます。
        

        

            スナップショットタイプ
            adOpenStatic
            adLockReadOnly
            
            レコードセットの内容を更新することは出来ません。
        

        

            テーブルタイプ
            
            
            adCmdTableDirect
            レコードの更新・追加・削除が可能.。seekメソッドを利用した高速検索が可能。
        

        

            読み取り専用
            
            adLockReadOnly
            
            レコードセットは，VBで更新することはできません。検索や並べ替えなど，レコードを更新する必要がない場合に利用します。
        

        

            
            adOpenKeyset
            adLockOptimistic

Option Explicit

Private Const cnCnString As String = "Provider=Microsoft.ACE.OLEDB.12.0;Data Source="
Private Const cnDbName As String = "testDB.accdb"
Private Const cnTblName As String = "Ttest" 'ID, Value1, Value2

'エクセルシートのテーブル内容を
'accdb のテーブルに追加する
Sub InsertIntoTest()
    
    '全レコード削除してから追加
    Call tblInit
    
    Dim xlTblName As String
    xlTblName = "[Sheet1$]"
    
    'accdbに接続
    Dim cn As ADODB.Connection
    Dim cmd As ADODB.Command
    
    Set cn = CreateObject("ADODB.Connection")
    
    With cn
        .ConnectionString = cnCnString & ThisWorkbook.Path & "\" & cnDbName
        .Mode = adModeShareExclusive '排他制御
        .Open
    End With
    
    Set cmd = CreateObject("adodb.command")
    
    
    'エクセルのシートをテーブルとて取得するコネクション
    Dim cnXl As ADODB.Connection
    Dim rsXl As ADODB.Recordset
    
    Set cnXl = CreateObject("adodb.connection") 'New ADODB.Connection
    Set rsXl = CreateObject("adodb.recordset") 'New ADODB.Recordset
    
    With cnXl
        .ConnectionString = cnCnString & ThisWorkbook.FullName
        .Properties("Extended Properties") = "Excel 12.0;HDR=YES"
        .Open
    End With
    
    With rsXl
        .ActiveConnection = cnXl
        .CursorType = adOpenForwardOnly
        .LockType = adLockPessimistic
        .Open "[Sheet1$]"
    End With
    
    cn.BeginTrans
    
    'つってもループ以外の方法はないっぽい
    Do Until rsXl.EOF
        With cmd
            .ActiveConnection = cn
            '↓テーブルオブジェクトじゃないので結局ループで廻すより方法がないっぽい
            '.CommandText = "insert into " & cnTblName & " select * from " & rsXl
            .CommandText = "insert into " & cnTblName & " (ID, value1, value2) values(" & rsXl(0) & ",'" & rsXl(1) & "','" & rsXl(2) & "')"
            .Execute
            rsXl.MoveNext
        End With
    Loop
    
    cn.CommitTrans
    
    Set cmd = Nothing
    cn.Close
End Sub

        .ConnectionString = cnCnString & ThisWorkbook.Path & "\" & cnDbName
        .Mode = adModeShareExclusive
        .Open
    End With
    
    Set rs = CreateObject("adodb.recordset")
    With rs
        .ActiveConnection = cn
        'カーソルタイプを動的にする事で削除SQLを実行できる?
        'カーソルタイプのディフォルトはadOpenForwardOnly

Sub テキストファイルの読み込み()


    Dim myCon As New ADODB.Connection
    Dim myRS As New ADODB.Recordset
    Dim myFolder As String
    Dim myTxt As String
    
    myFolder = ThisWorkbook.Path
    myTxt = "data.csv"
    
    With myCon
        .Provider = "Microsoft.Jet.OLEDB.4.0"
        .Properties("Extended Properties") = "TEXT"
        .Open myFolder
    End With
    
    myRS.Open _
        Source:=myTxt, _
        ActiveConnection:=myCon, _
        Options:=adClipString

    Set myCon = Nothing

Sub 先頭レコード､最終レコードを判定する()


     Dim myCon As New ADODB.Connection
     Dim myRS As New ADODB.Recordset
     Dim myIdx As Long

     Const strDB As String = _
        "c:\my documents\あああ\ｄｄｄｄ\db1.mdb"
    
     myIdx = InputBox("取り出したいレコードの位置を数字で入力")

     With myCon
        .ConnectionString = _
            "provider=microsoft.jet.oledb.4.0;" & _
            "data source=" & strDB & ";"
        .Open
     End With

     With myRS
        .Open "expack最終", myCon, adOpenStatic
        .Move Val(myIdx) - 1, adBookmarkFirst
     End With
     
     If myRS.EOF Or myRS.BOF Then
        MsgBox "其の位置にレコードは存在しません", vbCritical, ThisWorkbook.Name
     Else
        MsgBox myRS!ID & vbNewLine & myRS!店舗名 & vbNewLine & myRS!販売数, vbInformation, ThisWorkbook.Name
     End If

End Sub

Sub ブックマークを利用する()


    Dim myCon As New ADODB.Connection
    Dim myRS As New ADODB.Recordset
    Dim myBookmark As Variant
    
    With myCon
        .ConnectionString = _
            "provider=microsoft.jet.oledb.4.0;" & _
            "data source=" & ThisWorkbook.Path & "\adorenshu.mdb;"
        .Open
    End With
    
    myRS.Open "data", myCon, adOpenStatic, adLockReadOnly, adCmdTable
    
    '5番目のレコード移動（第2引数は”1レコード目から数えて5番目”という指定
    myRS.Move 4, adBookmarkFirst
    'カレントレコードをブックマークとして登録
    myBookmark = myRS.Bookmark
    '最終レコードへ移動
    myRS.MoveLast
    'ブックマークへ移動
    myRS.Bookmark = myBookmark
    
    MsgBox myRS.GetString(adClipString, 1, ",")
    
    '複数のブックマーク
    Dim myBookmarks(9) As Variant
    Dim i As Long
    
    '2つおきにブックマーク
    myRS.MoveFirst
    For i = 0 To 9
        myBookmarks(i) = myRS.Bookmark
        Debug.Print myRS.GetString(adClipString, 1, ",")
        myRS.Move 2
    Next i
    
    'つけたブックマークでフィルタ
    myRS.Filter = myBookmarks
    Sheet1.[a2].CopyFromRecordset myRS
     
    MsgBox "1行おきに" & UBound(myBookmarks) & "件抽出しました"
    myRS.Close
    Set myRS = Nothing
    myCon.Close
    Set myCon = Nothing
    
End Sub

Function chkTable_name(myfile As String, myName As String) _
    As Boolean

    Dim myCon As New ADODB.Connection
    Dim myRS As New ADODB.Recordset
    
    With myCon
        .Provider = "microsoft.jet.oledb.4.0;"
        .Properties("extended properties") = "excel 8.0"
        .Open myfile
    End With
    
    Set myRS = myCon.OpenSchema(adSchemaTables)
    myRS.Filter = "TABLE_NAME = '" & myName & "'"
    
    If myRS.RecordCount > 0 Then
        chkTable_name = False
    Else
        chkTable_name = True
    End If
    
    myRS.Close
    Set myRS = Nothing
    myCon.Close
    Set myCon = Nothing

End Function


Sub シート上のデータをmdbに追加()


    Dim myCon As New ADODB.Connection
    Dim myRS As New ADODB.Recordset
    Dim strDB As String
    Dim strTbl As String
    Dim rngR As Range
    Dim i As Long, j As Long
    
    strDB = ThisWorkbook.Path & "\adoRenshu.mdb"
    'C:\WINDOWS\ﾃﾞｽｸﾄｯﾌﾟ\aaa\adoRenshu.mdb
    strTbl = "data"
    
    Set rngR = ThisWorkbook.Worksheets("data").[a1].CurrentRegion
    
    With myCon
        .Provider = "microsoft.jet.oledb.4.0;"
        .Open strDB
    End With
    'アクセス側のレコードセットをmyRSに代入
    With myRS
        .Open strTbl, myCon, adOpenStatic, adLockPessimistic, adCmdTableDirect
        .Index = "PrimaryKey"
    End With
        
    For i = 2 To rngR.Rows.Count
        myRS.Seek rngR(i, 1).Value 'キー列を検索
        If myRS.EOF Then
            myRS.AddNew
                For j = 1 To rngR.Columns.Count
                    myRS.Fields(rngR(1, j).Value).Value = rngR(i, j).Value
                Next j
                '値を入れていく
        Else
            'キー重複時は該当レコードの背景色を赤
            rngR.Rows(i).Interior.ColorIndex = 45
        End If
    Next i
    
    myRS.Update
    myRS.Close
    Set myRS = Nothing
    myCon.Close
    Set myCon = Nothing

End Sub

Sub テーブル作成(ByRef strDbPth As String)


    Dim strCon As String
    Dim adxCat As New ADOX.Catalog
    Dim adxTbl As ADOX.Table
    Dim adxIdx As ADOX.Index
    
    strCon = _
        "provider=microsoft.jet.oledb.4.0;" & _
        "data source=" & strDbPth
        
    adxCat.ActiveConnection = strCon
    
    Set adxTbl = New ADOX.Table
    adxTbl.Name = "tb1"
    
    With adxTbl.Columns
        .Append "id", adSmallInt
        .Append "name", adVarWChar, 20
        '.Append "aa",adVarChar←データ型エラーになるadVarCharは”文字列値”なぜエラーになるのか不明
        .Append "price", adCurrency
    End With
    
    Set adxIdx = New ADOX.Index

    With adxIdx
        .Name = "主キー"
        .Columns.Append "id"
        .PrimaryKey = True
    End With
    
    adxTbl.Indexes.Append adxIdx
    
    adxCat.Tables.Append adxTbl
    
    Set adxIdx = Nothing
    Set adxTbl = Nothing
    Set adxCat = Nothing

End Sub
